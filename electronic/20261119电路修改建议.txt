                  2026-11-19 金属探测 (P1_metal) 电路修改建议
====================================================================

一、激励脉冲高通微分与栅极保护级（C101、R101、D101、Q101）
--------------------------------------------------------------------
1. 将 D101、R101 移到 C101 右边（即 C101 与 Q101 栅极之间）
   - 修改前问题：
     若 R101、D101 放在 C101 左边（靠近 MCU IO 侧），C101 右端（Q101 栅极）
     处于直流通路悬空状态，既无法形成 RC 高通微分限宽，也无法在脉冲拉低时快速
     泄放 C101 上的电荷。
   - 修改后接法：
     P1_METAL_PULSE (IOB1) -> R102 (1K) -> C101 (22nF) -> [Q101 栅极节点]
     在 [Q101 栅极节点] 处：
     (1) R101 (10K) 接在 Q101 栅极与 GND 之间；
     (2) D101 (1N4148WS) 阳极接 GND，阴极接 Q101 栅极。
   - 硬件作用：
     (1) 硬件限时导通保护：当 P1_METAL_PULSE 输出高电平时，C101 与 R102+R101
         构成高通微分电路（时间常数 τ = 11K × 22nF = 242us），使 Q101 仅导通
         约 150~250us 即自动截止，从硬件层面防止 MCU 跑飞或主循环阻塞时 Q103
         (AO3402A) 与线圈 L101 (300uH) 长时间大电流导通烧毁。
     (2) 快速复位泄放：当 P1_METAL_PULSE 拉低时，D101 正向导通将 Q101 栅极负向
         尖峰钳位在 -0.6V，并通过 R102 (1K) 以 τ = 1K × 22nF = 22us 快速放空
         C101 电荷，确保下一周期激励脉宽恒定。

2. 将 Q101 由 NPN 三极管 MMBT3904 更换为 N-MOSFET 2N7002 (C8545)
   - 修改原因：
     三极管基极-发射极结会把 C101 右端电压钳位在 0.65V 左右；改用高输入阻抗的
     2N7002 后，C101 右端可按理想 RC 指数曲线放电，关断时刻更明确、边沿更干净。


二、运放放大级阻容参数调整（C104、R111 —— 可直接在现有 PCB 上换件调试）
--------------------------------------------------------------------
1. 当前参数问题分析（当前 C104 = 105 / 1uF，R111 = 2MΩ）
   - 时间常数过大：
     τ = R111 × C104 = 2MΩ × 1uF = 2.0 秒（完全恢复稳态需 3τ~5τ ≈ 6~10 秒）。
     而脉冲涡流检测窗口仅在关断后的 200us~800us 内，2 秒的时间常数会导致每次脉冲、
     金属靠近或电源波动在 C104 上积累的电荷无法在脉冲间隔（50~100ms）内放完，造
     成严重的跨周期电荷累积、响应滞后（移上/移开金属需数秒恢复）以及易受电源干扰。
   - 耦合电容过大导致运放过载：
     C104 = 1uF 在每次反峰钳位跳变（约 0.7V）时向运放反相端注入约 700nC 电荷，
     远超 R111 (2MΩ) 所能提供的微安级反馈电流，迫使运放深度饱和撞轨。
   - 2MΩ 反馈电阻阻抗过高：
     在 PCB 上易受潮气、助焊剂漏电及电场耦合干扰。

2. 推荐修改参数（不改 PCB 走线，直接更换贴片元件）
   - C104：由 105 (1uF) 改为 222 (2.2nF) 或 472 (4.7nF)（最大不超过 103 / 10nF）。
   - R111：由 2MΩ 改为 200KΩ ~ 330KΩ。
     * 典型搭配 1：C104 = 2.2nF (222) + R111 = 220KΩ  =>  τ = 484us
     * 典型搭配 2：C104 = 4.7nF (472) + R111 = 150KΩ  =>  τ = 705us
   - 改后效果：
     (1) 时间常数精准匹配 500us 级涡流衰减尾迹；
     (2) 每次脉冲结束后 3~5ms 内运放即可 100% 恢复到静态偏置点，彻底消除跨周期
         电荷累积，金属靠近和移开均可实现毫秒级干脆响应；
     (3) 对 +4V5 电池电压波动和音频电流串扰的免疫力大幅提升。


三、后续 PCB 改版时的运放外围优化建议（R_in 与 C105）
--------------------------------------------------------------------
1. 在 C104 与 U101 反相输入端 (-IN, Pin 3) 之间串联一颗输入电阻 R_in = 4.7KΩ ~ 10KΩ
   - 原因与作用：
     目前 D102/D103 钳位点经 C104 直接连到运放 -IN，缺少串联限流/定增益电阻。
     串入 R_in (4.7KΩ ~ 10KΩ) 后，运放交流电压增益明确由 -R111 / R_in 决定（例如
     220K / 4.7K ≈ 47 倍），可避免运放输入端受大电流冲击深度饱和，使上升斜率与峰
     值随金属距离的变化更具线性度。

2. 将 U101 同相端偏置滤波电容 C105 改接在 +IN (Pin 1) 与 GND 之间
   - 原因与作用：
     当前原理图中 C105 (476 / 47uF) 一端接 U101 +IN，另一端接在 +4V5 电源轨上。
     当线圈开启或喇叭发声引起 +4V5 瞬态跌落时，接在 +4V5 上的 C105 会把电源纹波
     直接耦合进运放同相基准端。
     建议将 C105 改接在 U101 +IN 与 GND 之间（容值用 104/100nF 或 105/1uF 即可），
     使运放同相端基准电压对地保持纯净稳定。
